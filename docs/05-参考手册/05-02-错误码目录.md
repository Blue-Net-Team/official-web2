# 错误码目录

## 领域异常与 HTTP 状态码映射

| 领域异常 | HTTP 状态码 | 含义 |
|----------|-------------|------|
| `BadRequest` | 400 | 请求参数错误、业务校验失败 |
| `Unauthorized` | 401 | 未登录或认证信息无效 |
| `Forbidden` | 403 | 已登录但无权限访问 |
| `DataNotFound` | 404 | 请求的数据不存在 |
| `DataConflict` | 409 | 数据冲突，如重复提交、唯一约束冲突 |
| `TooManyRequests` | 429 | 请求过于频繁 |

## 统一响应格式

所有 REST 接口返回 `ResponseMessage<T>`：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

失败时：

```json
{
  "code": 400,
  "message": "具体错误描述",
  "data": null
}
```

## 业务错误码规划

当前项目主要通过 `ResponseMessage.code` 和 `message` 表达错误，未使用细粒度数字错误码。未来可按模块扩展：

| 模块 | 错误码区间 | 示例 |
|------|-----------|------|
| 认证 | 1000 - 1099 | 1001: 用户名或密码错误 |
| 用户 | 1100 - 1199 | 1101: 用户不存在 |
| 报名 | 1200 - 1299 | 1201: 学号已存在 |
| 文件 | 1300 - 1399 | 1301: 文件类型不支持 |
| 考核 | 1400 - 1499 | 1401: 考核时间未开始 |
| 考核队伍 | 1500 - 1599 | 1501: 邀请码无效 |
| 算法判题 | 1600 - 1699 | 1601: 判题任务不存在 |
| 权限 | 1700 - 1799 | 1701: 无权限访问 |
