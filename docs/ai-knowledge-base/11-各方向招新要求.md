# 蓝网团队各方向招新要求

## 统一要求

- 广东海洋大学大一或大二在读学生
- 态度认真、愿意自学
- 能投入一定时间
- 有团队协作意识

## 结构方向

**零基础要求：** 无特殊要求，对机械设计感兴趣即可

**加分项：**
- 有美术或设计基础
- 空间想象力好
- 喜欢动手做东西

**需要准备：** 能运行 SolidWorks 的电脑（游戏本更佳）

## 电控方向

**零基础要求：** 无特殊要求，对嵌入式开发感兴趣即可

**加分项：**
- 有 C 语言基础
- 了解过单片机
- 对电路有基本认知

**需要准备：** 普通笔记本即可

## 视觉方向

**零基础要求：** 无特殊要求，对编程感兴趣即可

**加分项：**
- 有 Python 基础
- 了解过图像处理
- 逻辑思维强

**需要准备：** 有自己的笔记本电脑（游戏本更佳，轻薄本也能用）

## 常见问题

**Q：三个方向只能选一个报名吗？**
A：是的，报名时选择一个主攻方向。考核期间不允许更换方向，入队后如果发现自己更适合其他方向，可以调整。

**Q：考核期间可以换方向吗？**
A：不可以。考核期间必须按照报名时选择的方向完成全部三轮考核。

**Q：考核未通过还能再报名吗？**
A：一般每年只有一次招新，但可以和学长沟通具体情况。
