# 结构方向详解

## 一句话解释

结构方向是机器人的"骨架和外壳"——负责机械结构设计、三维建模和加工装配。

## 做什么

- 使用 SolidWorks 进行三维建模和工程图绘制
- 机械结构设计与材料选型
- 加工图纸输出，配合 3D 打印或机加工完成零件制作
- 整机装配与结构调试

## 适合谁

- 机械设计制造及其自动化、工业设计等相关专业
- 对机械结构、三维设计感兴趣的同学
- 欢迎女生加入，结构方向不限性别

## 对口专业

以下专业与结构方向关联度较高，所学知识与方向技能匹配度好：

- **高度对口：** 机械设计制造及其自动化、工业设计、机械电子工程
- **比较对口：** 车辆工程、材料成型及控制工程、智能制造工程、过程装备与控制工程
- **也可以加入：** 农业机械化及其自动化、能源与动力工程（只要是工科背景，对机械设计感兴趣即可）

## 对口岗位

结构方向积累的技能在就业市场上有明确对口岗位：

- **机械结构工程师** — 负责产品机械结构设计（最常见）
- **三维建模工程师 / CAD工程师** — 专注三维建模、工程图绘制
- **产品设计工程师** — 负责新产品从概念到量产的结构设计
- **工艺工程师** — 负责零件加工工艺、装配工艺设计
- **机器人结构工程师** — 服务机器人、工业机器人本体结构设计
- **模具设计工程师** — 注塑模具、冲压模具设计

## 零基础能加入吗

可以。

- SolidWorks 软件上手较快，约 1 周可掌握基本操作
- 重点在于能看懂机械制图（图纸）
- 团队没有统一培训，以自学为主，但学长会提供指导
- 考核本身就是引导学习的过程，一轮考核重点就是打基础

## 学习路径

```
SolidWorks 基础操作 → 机械制图识图 → 零件建模 → 装配体设计 → 工程图输出 → 材料与加工工艺
```

## 对电脑的要求

建议游戏本，运行 SolidWorks 更流畅。普通笔记本也可以用，但复杂装配体可能会卡顿。

## 相关比赛

以下比赛中结构方向负责的工作：

- **全国大学生机械创新设计大赛（机创赛）** — 负责整机机械结构设计、三维建模、装配体设计、材料选型与加工
- **全国大学生工程实践与创新能力大赛（工创赛）** — 负责赛题要求的机械结构设计与制作
- **高教杯先进成图大赛** — 负责三维建模、工程图绘制、装配体设计
- **天鹅杯智能农业装备大赛** — 负责农业机械的结构设计、传动机构设计
- **中国机器人及人工智能大赛** — 负责机器人本体结构设计、执行机构设计
- **全国大学生智能机器人创新创意大赛** — 负责机器人机械结构设计、运动机构设计
