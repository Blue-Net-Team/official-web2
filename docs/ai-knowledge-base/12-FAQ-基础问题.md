# FAQ：基础问题

## 没基础能加入蓝网团队吗？

**答：可以。**

三个方向都接受零基础新生加入：

- **结构方向：** SolidWorks 软件上手较快，约 1 周可掌握基本操作，重点在于能看懂机械制图
- **电控方向：** 零基础先从 C 语言开始学，有学长指导
- **视觉方向：** Python 上手容易，OpenCV 学习曲线平缓

团队没有统一培训，以自学为主，但学长会提供指导。考核本身就是引导学习的过程，一轮考核重点就是打基础。

**态度比基础更重要。** 只要你愿意学习、态度认真，零基础完全不是问题。往届有很多零基础加入的成员最终成为团队骨干。

---

## 不是机械/自动化/计算机专业的能加入蓝网团队吗？

**答：可以。**

蓝网科技创新团队不限专业，欢迎各专业的同学加入。

**各专业适配情况：**

- **结构方向：** 欢迎工业设计、机械设计制造及其自动化等相关专业，也欢迎其他对机械设计感兴趣的专业
- **电控方向：** 欢迎电子信息、电气工程等相关专业，也欢迎其他对嵌入式开发感兴趣的专业
- **视觉方向：** 欢迎计算机、软件工程等相关专业，也欢迎数学、物理等对编程感兴趣的专业

**往届情况：** 团队中有很多非对口专业的优秀成员，通过自学和团队氛围的带动，同样取得了很好的成绩。

专业不是门槛，兴趣和学习意愿才是关键。

---

## 女生适合加入蓝网团队吗？

**答：适合。**

蓝网科技创新团队欢迎女生加入，团队不限性别。

**具体情况：**

- 结构方向不限性别，非常欢迎女生加入
- 团队有女生成员，也有女生担任过核心职务
- 机器人团队的性质不以体力为主，更注重设计和思维，女生完全可以胜任

**往届情况：** 团队中有女生成员在结构、视觉等方向都有出色表现。

性别不是加入团队的障碍，兴趣和能力才是关键。如果你对机器人技术感兴趣，不论男女都可以报名加入。
