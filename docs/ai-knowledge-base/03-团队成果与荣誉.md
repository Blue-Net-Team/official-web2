# 蓝网团队成果与荣誉

## 参赛经历

蓝网科技创新团队每年代表广东海洋大学参加多项国家级、省级科技竞赛：

### 核心赛事
- 全国大学生工程实践与创新能力大赛（工创赛）
- 全国大学生机械创新设计大赛（机创赛）
- 全国大学生电子设计竞赛（电赛）

### 其他赛事
- 中国国际"互联网+"大学生创新创业大赛
- 中国机器人及人工智能大赛
- 全国大学生智能机器人创新创意大赛
- 高教杯先进成图大赛
- 高教杯数学建模大赛
- 嵌入式设计大赛
- 蓝桥杯大赛
- 天鹅杯智能农业装备大赛

## 获奖概况

团队成立13年来，累计获得省级以上奖项数十项，涵盖机械设计、电子控制、人工智能等多个领域。

## 团队传承

13年的发展历程中，团队培养了大量具有工程实践能力的优秀成员，毕业生分布在智能制造、自动化、互联网等行业。
