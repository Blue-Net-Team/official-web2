# 蓝网团队三个技术方向介绍

蓝网科技创新团队分为三个核心技术方向，每个方向负责机器人系统的不同部分。

## 结构方向

- **定位：** 机器人的"骨架和外壳"
- **核心工作：** 机械结构设计、三维建模、加工装配、材料选型
- **主要工具：** SolidWorks
- **输出成果：** 机械零件、装配体、工程图纸

## 电控方向

- **定位：** 机器人的"神经和肌肉"
- **核心工作：** 电路设计、嵌入式编程、电机控制、传感器调试
- **主要工具：** Keil、STM32开发板
- **输出成果：** 控制程序、电路板、驱动系统

## 视觉方向

- **定位：** 机器人的"眼睛和大脑"
- **核心工作：** 图像识别、目标检测、路径规划、AI算法
- **主要工具：** Python、OpenCV
- **输出成果：** 视觉算法、识别模型、导航程序

## 三方向协作关系

一个完整的机器人项目需要三个方向协同完成：
- 结构方向搭建机械本体
- 电控方向实现运动控制
- 视觉方向提供感知能力

在第三轮考核和正式比赛中，三个方向的成员会组成完整队伍共同完成赛题。
