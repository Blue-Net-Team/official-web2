# 各方向软件的使用

## 结构设计

结构设计一般使用CAD软件，即**计算机辅助设计软件**，实验室常用软件包括（同时也是考核指定的软件）

- AutoACD 二维工业绘图工具，一般用较新版本（落后于当前年份1~2年的版本，如今年为2026，可以使用2024版）
- Solidwork 三维工业绘图工具，内置了仿真等功能，一般使用最新版本

根据个人情况，还可以使用

- UG NX 西门子出品的三维工业绘图工具，也是制造业企业常用的软件
- inspire “高教杯”制图大赛 轻量化设计赛项指定软件，用于机械结构拓扑优化和仿真
- Ansys 工业常用仿真软件，内置流体仿真、传热仿真、结构力学仿真、拓扑优化等功能
- COMSOL 多物理场仿真软件

## 电路控制

电控方向一般使用C语言、单片机、PCB相关的软件，实验室常用软件包括（同时也是考核指定的软件）

- Visual Studio，简称VS，可以作为C语言的集成开发工具，已经内置了C语言的编译运行环境，无需再安装gcc和clang等编译器），可以作为C语言入门的编程软件
- keil uvision5，单片机编译与烧录工具，可以配置实验室常用芯片stm32 f1/f4芯片的支持包，支持编译、烧录、调试
- 立创EDA，嘉立创出品的PCB原理图绘制、layout、打样软件，用于PCB设计

另外的，根据个人情况，也可以使用

- Visual Studio code，简称 vscode，类似于vs，但是不内置开发环境，需要手动配置gcc编译器进行C语言运行，如果要用于单片机，还需要配置CORTEX、ARMCC、openocd等工具链
- Altium Designer，简称AD，是一款PCB绘制工具，与立创EDA类似，是各大电子硬件公司的指定软件

## 计算机视觉

计算机视觉编写的语言为Python，可以根据自己的需要，下载开发工具

开发工具包括

- Pycharm
- vscode

下载开发工具后，还需要根据自身情况，配置Python解释器，可以使用

- anaconda
- uv
- python.org
