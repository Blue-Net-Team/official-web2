# 蓝网团队参加比赛的条件

## 基本原则

加入团队后，**都有机会**参加比赛。

## 参赛形式

- 自行组队参赛
- 团队组织选拔（参赛队伍较多的赛事）

## 需要选拔的比赛

对于参赛队伍较多的赛事，需要在团队内进行选拔：

- 各方向负责人或项目负责人组织选拔
- 选拔标准根据具体比赛要求确定
- 一般考察技术能力和团队协作能力

## 各年级参赛建议

| 年级 | 建议参赛类型 |
|------|-------------|
| **大一** | 边缘竞赛（中国机器人及人工智能大赛、智能机器人创新创意大赛等） |
| **大二** | 核心赛事（工创赛、机创赛、电赛等） |
| **大三** | 核心赛事 + 带队指导 |

## 如何获得参赛机会

1. **主动表达意愿** — 向方向负责人或学长说明想参赛
2. **提升技术能力** — 把基础打牢，有能力完成比赛任务
3. **积极组队** — 主动找队友，跨方向组队更有优势
4. **参与选拔** — 对于需要选拔的比赛，认真准备选拔考核

## 比赛周期

- 工创赛、机创赛等核心赛事一般每年一次
- 边缘竞赛时间比较灵活
- 团队会根据比赛节点安排备赛计划

# 蓝网团队日常工作与活动

## 会议安排

**没有固定例会。**

团队一般在以下情况组织会议：

- **赛前动员会：** 比赛前组织，分配任务、明确目标
- **学校检查：** 学校相关部门来检查时集中组织
- **赛后总结会：** 比赛结束后复盘，总结经验教训
- **报销会议：** 比赛费用报销相关事宜

## 实验室

**位置：** 工程训练中心（望海楼旁边）

**使用规则：**
- 不需要出勤打卡
- 没有具体出勤要求
- 自行安排时间到实验室学习和调试
- 实验室有基础设备和工具，可以使用

## 日常活动

- **自主学习：** 在实验室或宿舍自学技术
- **项目调试：** 到实验室调试机器人和电路
- **技术交流：** 和学长、队友讨论技术问题
- **比赛备赛：** 根据比赛节点集中备赛

## 团队氛围

- 比较自由，没有强制要求
- 靠自觉和兴趣驱动
- 学长比较愿意指导，但需要主动问
- 团队协作氛围好，跨方向交流频繁

## 建议

- 多去实验室，和学长面对面交流效率更高
- 主动参与讨论，不要害羞
- 有比赛时积极投入，平时保持学习节奏
