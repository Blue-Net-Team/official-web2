# 蓝网团队比赛报销与奖金说明

## 比赛费用报销

### 可报销费用

参加比赛产生的以下费用可以申请报销：

- **材料费**：购买比赛所需元器件、耗材、零部件等的费用。
- **报名费**：比赛官方收取的报名费用。
- **差旅费**：外出参赛产生的交通、住宿等费用。

### 报销要求

- **材料费发票限制**：单个商品的发票金额不能高于 **500 元**。
- **提前沟通**：参加比赛前必须与实验室指导老师沟通确认。未经沟通自行参赛，相关费用可能无法报销。
- **指导老师选择**：参加比赛时，应尽可能选择本实验室的指导老师。不要找其他实验室指导老师挂名，否则可能影响报销和团队管理。

## 比赛奖金

### 基本原则

- 比赛奖金因比赛而异：**有些比赛有奖金，有些比赛没有**。
- 蓝网实验室参加的赛事大部分是教育部直属或官方学科竞赛，**一般不设奖金**。

### 可能有奖金的赛事

- 部分省级赛事、创业类赛事或综合类大赛（例如中国国际大学生创新大赛、广东“众创杯”等）可能设有奖金，或有学校的配套奖励。
- 具体奖金金额、发放方式以及当年是否有奖金，**以比赛官方通知和学校政策为准**，参赛前可向指导老师确认。

## 参赛建议

1. **参赛前先沟通**：报名或购买材料前，先与实验室指导老师确认报销政策、预算和指导老师安排。
2. **保留凭证**：所有发票、缴费记录、行程单据请妥善保存，报销时需要提供。
3. **指导老师优先本实验室**：便于报销审核和后续团队资源协调。
4. **理性看待奖金**：参加比赛的重心应放在能力提升、项目经验和赛事荣誉上，不要以奖金为主要目的。
