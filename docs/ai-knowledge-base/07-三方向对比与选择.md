# 蓝网团队三方向对比

| 对比项 | 结构 | 电控 | 视觉 |
|--------|------|------|------|
| **核心工具** | SolidWorks | Keil + STM32 | Python + OpenCV |
| **主要语言** | 无（软件操作） | C/C++ | Python |
| **硬件接触** | 3D打印、机加工 | 电路板、开发板 | 摄像头、树莓派 |
| **零基础难度** | 低（软件好学） | 中（需要理解寄存器） | 低（Python友好） |
| **对电脑要求** | 一般（能跑SolidWorks） | 一般 | 较高（建议游戏本） |
| **培训形式** | 自学为主，学长指导 | 自学为主，学长指导 | 自学为主，学长指导 |
| **比赛应用** | 机械结构设计 | 控制逻辑、电路 | 识别、定位、导航 |
| **高度对口专业** | 机械、工业设计 | 自动化、电气、电子 | 计算机、软件、AI |
| **典型对口岗位** | 结构工程师、CAD工程师 | 嵌入式工程师、硬件工程师 | 算法工程师、视觉工程师 |

## 如何选择方向

**选结构，如果你：**
- 喜欢动手做东西，对机械设计感兴趣
- 空间想象力好，能看懂图纸
- 不排斥画图和建模

**选电控，如果你：**
- 对编程和电路都有兴趣
- 喜欢调试硬件，解决问题
- 愿意钻研底层原理

**选视觉，如果你：**
- 喜欢编程，Python 入门快
- 对图像处理、AI 感兴趣
- 逻辑思维强，喜欢算法

## 方向可以换吗

可以。入队后如果发现自己更适合其他方向，可以调整。团队有成员从视觉方向起步，后续通过自我学习实现了多方向全能发展。个人发展不受任何限制。
