# 蓝网团队招新流程

## 整体流程

```
官网报名 → 面试（与学长交流）→ 获得考核资格 → 三轮考核 → 正式入队
```

## 第一步：官网报名

访问蓝网官方网站，点击"加入我们"页面填写报名信息。

## 第二步：面试

- 面试形式轻松，主要是与学长聊聊基本情况、兴趣爱好、加入动机
- 面试通过后才获得考核资格
- 面试目的是了解你是否适合团队氛围，不涉及技术考核

## 第三步：三轮考核

获得考核资格后，需要完成三轮考核：

1. **第一轮：基础能力考核**（各方向不同，详见"三轮考核详情"）
2. **第二轮：方向专项考核**（限时任务或小项目）
3. **第三轮：综合团队考核**（跨方向组队完成赛题）

**重要：考核期间不允许更换方向。** 报名时选择的方向将贯穿整个考核过程，请务必慎重选择。

## 第四步：正式入队

通过三轮考核后，正式成为蓝网科技创新团队成员。

## 时间安排

- 秋季开学启动招新
- 国庆假期后截止报名
- 面试和考核在报名截止后陆续进行
- 整个招新流程一般持续 3 个月
