# 视觉方向详解

## 一句话解释

视觉方向是机器人的"眼睛和大脑"——负责图像识别、目标检测和路径规划。

## 做什么

- 基于 Python + OpenCV 的图像处理与视觉算法开发
- 目标检测、颜色识别、轮廓提取等传统视觉算法
- 基于树莓派等 Linux 开发板的视觉系统部署
- 部分项目涉及深度学习（后续方向）

## 适合谁

- 计算机、软件工程、自动化等相关专业
- 对计算机视觉、图像处理感兴趣的同学
- 有自己的笔记本电脑（游戏本即可）

## 对口专业

以下专业与视觉方向关联度较高，所学知识与方向技能匹配度好：

- **高度对口：** 计算机科学与技术、软件工程、人工智能、智能科学与技术
- **比较对口：** 数据科学与大数据技术、自动化（模式识别方向）、电子信息工程（图像处理方向）
- **也可以加入：** 应用数学、信息与计算科学（算法基础好）、统计学（数据分析方向）、测控技术与仪器（偏视觉检测）

## 对口岗位

视觉方向积累的技能在就业市场上有明确对口岗位：

**视觉核心岗位：**
- **计算机视觉算法工程师** — 负责图像识别、目标检测等算法开发（最常见）
- **图像处理工程师** — 专注传统图像处理、视觉检测系统
- **AI算法工程师** — 深度学习模型训练、部署与优化
- **机器视觉工程师** — 工业视觉检测、测量、定位系统开发
- **自动驾驶感知工程师** — 负责环境感知、目标跟踪、SLAM等
- **机器人视觉工程师** — 服务机器人、工业机器人视觉系统开发

**可转岗方向（软件组属性）：**
视觉方向以编程为核心，Python 基础扎实、算法思维强，**转软件开发非常顺畅**。团队内部视觉方向也偏向软件组管理。

- **Python后端开发工程师** — Web后端、API开发、数据处理服务
- **软件开发工程师** — 通用软件系统开发，编程基础可直接复用
- **测试开发工程师** — 自动化测试、测试工具开发（Python脚本能力强）
- **数据工程师 / 数据分析师** — 数据处理、可视化、数据 pipeline 开发

## 零基础能加入吗

可以。

- Python 上手容易，OpenCV 学习曲线平缓
- 数学要求不高，传统视觉算法以工程实现为主
- 深度学习可以放后面再学，入门阶段以传统视觉为主
- 实验室没有统一 GPU 算力资源，一般用自己的游戏本即可训练模型，但入门阶段基本用不到深度学习

## 学习路径

```
Python 基础 → OpenCV 图像处理 → 传统视觉算法（颜色/轮廓/模板匹配）→ 树莓派/Linux 开发板 → 相机标定与路径规划 → 深度学习（进阶）
```

## 对电脑的要求

建议游戏本，训练模型更方便。轻薄本也能用但模型训练可能较慢；也可以使用第三方算力平台或服务器。

## 相关比赛

以下比赛中视觉方向负责的工作：

- **全国大学生工程实践与创新能力大赛（工创赛）** — 负责赛题中的视觉识别、目标检测
- **全国大学生机械创新设计大赛（机创赛）** — 负责涉及视觉识别的功能模块（如自动识别分拣等）
- **全国大学生智能机器人创新创意大赛** — 负责机器人视觉导航、目标识别、环境感知
- **中国机器人及人工智能大赛** — 负责越障中的目标检测、图像处理
- **蓝桥杯大赛** — 负责算法编程、图像处理算法实现
- **高教杯数学建模大赛** — 负责模型构建、数据处理、算法编程
- **全国大学生电子设计竞赛（电赛）** — 参与涉及图像采集与处理的题目模块
