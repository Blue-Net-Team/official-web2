# 蓝网团队三轮考核详情

## 第一轮：基础能力考核

根据报考方向完成对应的基础任务：

| 方向 | 考核内容 |
|------|----------|
| **结构** | SolidWorks 基础绘图 |
| **电控** | C 语言基础 |
| **视觉** | Python 基础 |

**说明：** 一轮考核的目的是引导你打基础，不需要精通，态度认真即可。考核本身就是学习过程。

## 第二轮：方向专项考核

| 方向 | 考核形式 |
|------|----------|
| **结构** | 限时绘图任务 |
| **电控** | 完成一个小项目（如寻迹小车）|
| **视觉** | 限时算法题 |

**说明：** 二轮考核考察方向专项能力，需要在一轮基础上有所进阶。

## 第三轮：综合团队考核

**形式：** 结构、电控、视觉三个方向的同学自由组队

**任务：** 在规定时间内（一般为一个月）合作完成一个赛题

**目的：** 考察团队协作能力、跨方向沟通能力和综合工程实践能力

**说明：** 三轮考核是最接近真实比赛的体验，也是团队评估你是否适合团队的重要依据。

## 考核期间支持

- **可以来实验室自习：** 考核期间欢迎到工程训练中心实验室自习，使用实验室设备
- **可以找学长交流：** 遇到问题可以找学长请教，团队氛围比较开放

## 考核建议

- 不要临时抱佛脚，考核周期内保持持续学习
- 遇到问题主动问学长，团队氛围比较开放
- 态度比当前水平更重要，认真完成考核任务即可
