# 环境配置

本文档介绍 BlueNet 项目本地开发环境的依赖安装、服务配置和环境变量说明。Docker 部署请见 [04-02-Docker部署](./04-02-Docker部署.md)。

## 环境要求

### 后端

| 工具 | 版本要求 | 说明 |
|------|---------|------|
| JDK | 21+ | Java 开发环境 |
| Maven | 3.9+ | 项目构建工具 |
| PostgreSQL | 15+ / 17+ | 主数据库 |
| Redis | 7.x | 缓存服务（可选） |
| RabbitMQ | 3.x | 消息队列（可选） |
| MinIO | 最新版 | 对象存储 |

### 前端

| 工具 | 版本要求 | 说明 |
|------|---------|------|
| Node.js | 20+ | JavaScript 运行时 |
| pnpm | 9+ | 包管理器 |

## 服务配置详解

### PostgreSQL

**Windows**：下载安装包 https://www.postgresql.org/download/windows/，设置密码和端口（默认 5432），将 `C:\Program Files\PostgreSQL\17\bin` 加入 PATH。

**Linux**：
```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl enable postgresql
sudo systemctl start postgresql
```

**macOS**：
```bash
brew install postgresql@17
brew services start postgresql@17
```

**创建数据库**：
```bash
psql -U postgres
CREATE DATABASE db_blue_net;
CREATE USER bluenet WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE db_blue_net TO bluenet;
\q
```

### MinIO

**Windows**：
```powershell
minio.exe server C:\minio-data --console-address ":9001"
```

**Linux**：
```bash
wget https://dl.min.io/server/minio/release/linux-amd64/minio
chmod +x minio
sudo mv minio /usr/local/bin/
sudo mkdir -p /data/minio
minio server /data/minio --console-address ":9001"
```

**Docker**：
```bash
docker run -d \
  --name minio \
  -p 9000:9000 \
  -p 9001:9001 \
  -v minio_data:/data \
  -e MINIO_ROOT_USER=admin \
  -e MINIO_ROOT_PASSWORD=your_password \
  minio/minio server /data --console-address ":9001"
```

> 注意：若后端通过 Docker Compose 与 MinIO 同网络运行，且前端/浏览器需要直接访问预签名 URL，则必须在 `.env` 中配置 `MINIO_PUBLIC_URL` 为宿主机可访问的外部地址（如 `http://192.168.1.100:7000`）。不要设置 `MINIO_SERVER_URL` 环境变量给 MinIO 容器。

系统按文件类型划分存储桶，应用启动时 `MinioConfig` 会自动创建：`avatar`、`normal-img`、`assessment-attachment`、`work`、`qrcode`。

### Redis

```bash
docker run -d \
  --name redis \
  -p 6379:6379 \
  -v redis_data:/data \
  redis:7-alpine redis-server --appendonly yes
```

### RabbitMQ

```bash
docker run -d \
  --name rabbitmq \
  -p 5672:5672 \
  -p 15672:15672 \
  -v rabbitmq_data:/var/lib/rabbitmq \
  -e RABBITMQ_DEFAULT_USER=admin \
  -e RABBITMQ_DEFAULT_PASS=bluenet123 \
  rabbitmq:3-management
```

管理界面：http://localhost:15672

### SMTP 邮件服务

项目默认使用 163 邮箱 SMTP。需在邮箱设置中开启 SMTP 并获取授权码。

```yaml
spring:
  mail:
    host: smtp.163.com
    port: 465
    username: your_email@163.com
    password: your_auth_code
```

## 环境变量说明

后端本地开发使用 `src/backend/.env`，从 `.env.example` 复制并填写实际值。完整变量列表见原模板，关键变量如下：

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `DATABASE_HOST` | 否 | `localhost` | 数据库主机 |
| `DATABASE_PORT` | 否 | `5432` | 数据库端口 |
| `DATABASE_NAME` | 否 | `db_blue_net` | 数据库名称 |
| `DATABASE_USERNAME` | 否 | `postgres` | 数据库用户名 |
| `DATABASE_PASSWORD` | 是 | - | 数据库密码 |
| `STORAGE_PROVIDER` | 否 | `minio` | `minio` 或 `aliyun-oss` |
| `MINIO_ENDPOINT` | 否 | `localhost` | MinIO 内部访问地址 |
| `MINIO_PUBLIC_URL` | 建议 | - | 浏览器访问 MinIO 的地址，Docker 环境必填 |
| `JWT_SECRET` | 是 | - | JWT 签名密钥，至少 32 字符 |
| `COOKIE_SECURE` | 否 | `false` | 生产环境必须 `true` |
| `CORS_ALLOWED_ORIGINS` | 否 | `*` | 生产环境必须配置具体域名 |
| `GITHUB_CLIENT_ID` | OAuth 时 | - | GitHub OAuth App Client ID |
| `GITHUB_CLIENT_SECRET` | OAuth 时 | - | GitHub OAuth App Client Secret |

前端环境变量：`src/frontend/.env`，关键变量：

| 变量 | 说明 |
|------|------|
| `BACKEND_HOST` / `BACKEND_PORT` | SSR 时后端地址 |
| `NEXT_PUBLIC_BACKEND_HOST` / `NEXT_PUBLIC_BACKEND_PORT` | CSR 时后端地址 |
| `NEXT_PUBLIC_SSL_ENABLED` | 是否 HTTPS |

> `NEXT_PUBLIC_` 前缀变量会打包到客户端，不要包含敏感信息。

## 开发环境配置

开发环境使用 `application-dev.yml`，默认激活。

```bash
# 后端
cd src/backend
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev

# 前端
cd src/frontend
pnpm dev
```

| 服务 | 地址 |
|------|------|
| 后端 API | http://localhost:8080 |
| 前端页面 | http://localhost:3000 |
| MinIO 控制台 | http://localhost:9001 |

## 生产环境配置

生产环境使用 `application-prod.yml`。

安全要求：
- `COOKIE_SECURE=true`
- `CORS_ALLOWED_ORIGINS` 配置具体域名
- `JWT_SECRET` 使用强密钥
- 数据库密码使用强密码

```bash
java -jar target/bluenet-backend-*.jar --spring.profiles.active=prod
```

## 常见问题

### 数据库连接失败

1. 确认 PostgreSQL 已启动。
2. 检查连接参数：`psql -h localhost -U postgres -d db_blue_net`
3. 检查 `pg_hba.conf` 允许密码认证。
4. 检查防火墙。

### 预签名 URL 上传失败（SignatureDoesNotMatch）

- 确保 `MINIO_PUBLIC_URL` 是浏览器实际访问 MinIO 的地址。
- Docker 环境使用宿主机可访问的外部地址，如 `http://192.168.1.100:7000`。
- 不要给 MinIO 容器设置 `MINIO_SERVER_URL`。

### CORS 跨域错误

- 开发环境可配置为 `*`。
- 生产环境必须配置具体域名：`https://your-domain.com,https://www.your-domain.com`。

### Flyway 迁移失败

```bash
./mvnw flyway:info
./mvnw flyway:clean    # 仅开发环境
./mvnw flyway:migrate
```
