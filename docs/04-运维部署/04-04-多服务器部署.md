# 多服务器部署

本文档描述 BlueNet 多服务器部署的通用架构与流程。具体 IP、域名、密钥等敏感信息请通过 GitHub Secrets 或 Vault 管理，不要写入仓库。

## 角色划分

| 角色 | 说明 | 建议规格 |
|------|------|----------|
| Web 服务器 | Nginx 反向代理、静态资源 | 1 台 |
| 应用服务器 | 后端 API Service、AI Service | 1+ 台 |
| 前端服务器 | 前端 Frontend Service | 1 台（可与应用服务器同机） |
| 数据库服务器 | PostgreSQL、Redis | 1 台 |
| 消息/存储服务器 | RabbitMQ、MinIO | 1 台 |
| 判题服务器 | Judge Service | 1+ 台 |

## 可分离部署模型

所有服务支持“可分离”部署：通过 `<SERVICE>_DEPLOY_*` Secrets 指定独立主机与路径，未配置时回退到全局 `DEPLOY_*`。

### 同机部署（默认）

不配置任何 `<SERVICE>_DEPLOY_*`，所有服务部署到 `DEPLOY_HOST_*` 指定的同一台服务器。行为与历史版本一致。

### 同机分离目录

配置 `API_DEPLOY_PATH_*` 与 `FRONTEND_DEPLOY_PATH_*` 为不同目录，但 `HOST` 相同。适用于同一台服务器上需要隔离部署目录的场景。

### 跨机部署

配置 `API_DEPLOY_HOST_*` 与 `FRONTEND_DEPLOY_HOST_*` 为不同主机。此时：

- api-service 部署到 API 主机，使用 `--profile api` 启动。
- frontend 部署到前端主机，使用 `--profile frontend --no-deps` 启动。
- 前端主机的 `.env` 中 `BACKEND_HOST` 必须配置为 API 主机的公网/内网可访问地址，不能使用 `api-service`。

## 网络要求

- 应用服务器可访问数据库服务器（PostgreSQL 5432、Redis 6379）。
- 应用服务器与判题服务器可访问 RabbitMQ（5672）。
- 应用服务器与判题服务器可访问 MinIO（9000）。
- Web 服务器对外暴露 80/443，反向代理到内部服务。
- 生产环境所有服务间通信建议走内网，并配置防火墙。

## Secrets 配置

以下 Secret 需配置在 CI/CD 系统（如 GitHub Secrets）中，部署时通过 `scp` 或配置中心下发到服务器：

```bash
# 数据库
DATABASE_HOST=
DATABASE_PORT=5432
DATABASE_NAME=db_blue_net
DATABASE_USERNAME=
DATABASE_PASSWORD=

# Redis
REDIS_HOST=
REDIS_PORT=6379
REDIS_PASSWORD=

# RabbitMQ
RABBITMQ_HOST=
RABBITMQ_PORT=5672
RABBITMQ_USERNAME=
RABBITMQ_PASSWORD=

# MinIO
MINIO_ENDPOINT=
MINIO_PORT=9000
MINIO_AK=
MINIO_SK=
MINIO_PUBLIC_URL=

# JWT
JWT_SECRET=

# GitHub OAuth / App（可选）
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=
GITHUB_APP_ID=
GITHUB_APP_PRIVATE_KEY_PATH=

# AI Service（可选）
TBD_RAG_SILICONFLOW_API_KEY=
TBD_RAG_DEEPSEEK_API_KEY=
```

## 部署流程

1. **准备服务器**：按角色划分安装 Docker、Docker Compose。
2. **配置 Nginx**：参考 [04-05-Nginx配置建议](./04-05-Nginx配置建议.md)。
3. **下发 `.env`**：将 Secrets 写入各服务器对应路径的 `.env` 文件，权限设为 `600`。
4. **拉取镜像**：通过 CI/CD 构建并推送镜像到镜像仓库，服务器拉取最新镜像。
5. **启动服务**：
   ```bash
   docker compose --profile full up -d
   ```
6. **健康检查**：访问 `/actuator/health` 或对应健康检查接口。
7. **回滚**：保留上一个版本的镜像标签，异常时快速切换。
