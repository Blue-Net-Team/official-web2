# AI 对话记录后台 · 页面结构规格

本文档由 `docs/UI/ai-monitor.pen` 设计稿导出，是前端实现的**结构依据**。
设计稿本身已定稿并经需求确认，实现时请照此还原。

设计基准视口：**1440 × 1024**。

---

## 0. 全局约定

### 页面骨架（三页共用，由 `app/admin/layout.tsx` + `AdminNav` 提供）

```
┌─ AdminHeadBar  高 64，深色 #19191c ─────────────────────────────┐
├──────────────┬──────────────────────────────────────────────────┤
│ AdminSideBar │ Content  padding 24，纵向 flex，gap 16           │
│ 宽 200       │ 可用内容宽度 1192                                 │
│ 深色 #19191c │                                                  │
└──────────────┴──────────────────────────────────────────────────┘
```

- 页面**不要**自己包 `ConfigProvider`：全局 `ThemeProvider` 已设 `theme.darkAlgorithm` + `colorPrimary: #fa8c16`
- 内容区背景为全局 `#000000`；卡片用 antd `Card`（主题里已配 `colorBgContainer: rgba(255,255,255,0.03)`）
- 圆角 `borderRadius: 12`
- 文字层级用 antd token：`colorText` / `colorTextSecondary` / `colorTextTertiary` / `colorTextQuaternary`
- 卡片内边距 20，卡片之间 gap 16

### 语义色（**仅用于标签、状态点与图表条**，不要用于大面积填充）

| 含义 | 设计稿 token | 建议取值 |
|---|---|---|
| 检索 / 主色 | `primary` | `#fa8c16` |
| 拒答 | `err` | `#ff4d4f` |
| 直接回复 | `cyan` | `#13c2c2` |
| 澄清 | `warn` | `#faad14` |
| 成功 / 最终答案 | `ok` | `#10b981` |
| 思考过程 / 预披露 | `purple` | `#9254de` |
| 次要轨道 / 底槽 | `track` | `rgba(255,255,255,0.1)` |
| 代码块底 | `code-bg` | `rgba(255,255,255,0.04)` |

### 表格列定义

| 列 | 宽 | 会话行 | 提问行（展开后） |
|---|---|---|---|
| 展开图标 | 32 | chevron-right / 展开时 chevron-down | `corner-down-right` 图标 13px 四级文字 |
| 时间 | 76 | `14:32` | `14:32:05`（等宽 11px 四级文字） |
| 会话 / 用户问题 | 填充 | `a3f2…`（等宽 12px）+ 首个提问摘要（13px 二级文字） | 提问原文（13px 一级文字） |
| 意图 | 136 | **聚合显示**：去重后取第一个意图标签，多于一个时追加 `+N`；无数据显示 `—` | 意图名（12px 二级）+ 置信度（等宽 11px 四级） |
| 动作 | 88 | **聚合显示**：去重后的动作标签，最多 2 个；无数据显示 `—` | 彩色标签 |
| 轮次 | 56 | **聚合显示**：该会话所有提问 `toolRounds` 之和，显示 `N 轮`；为 0 显示 `—` | `2 轮`（工具轮次 `toolRounds`；无工具调用显示 `—`） |
| 消息数 | 68 | `messageCount` 数字 | 空 |
| 耗时 | 76 | 总耗时 `11.2s` | 该提问耗时 `4.1s` |

行高：会话行 48，提问行 44。行内左右内边距 16，行底边框 `rgba(255,255,255,0.06)`。

### 关于「意图 / 动作 / 轮次」三列的会话行取值

**这三列在会话行也必须显示内容**，从 `turns` 聚合得出（数据本就在 `AiConversationSummaryDTO.turns` 里，无需额外接口）。

> 早期版本把会话行这三列留空，理由是「这些字段属于提问粒度」。但列表**默认全部折叠**，
> 导致这三列在默认状态下永远空白，表格看起来像坏了。
> 聚合显示后，不展开也能一眼看出“哪些会话被拒答了”“哪些问题标签没覆盖”。

### 行为（见 spec）

- 筛选：时间范围（映射 `startTime`/`endTime`）/ 意图 / 动作 / 关键词（`keyword`，只匹配用户提问原文）
- 分页：`page` 从 0 开始，默认 `size=20`
- 内嵌提问数量有上限，`hiddenTurnCount > 0` 时在末行显示「还有 N 轮 →」并可点击进详情
- 点会话行的提问 → 跳详情页并定位到该 `seq`
- 空状态、加载态、错误可重试

## 2. 会话详情页

路由：`/admin/ai-traces/conversations/[id]` → `app/admin/ai-traces/conversations/[id]/page.tsx`

### 纵向结构

```
① 面包屑行                                      高 34
   ← 返回列表   |   a3f2-9b71-4e02（等宽）   [3 次提问]   2026-09-15 14:32 – 14:33

② 左右分栏（gap 16）                             高 862
   ├─ 左栏 Card  宽 264
   │    标题「本会话消息」12px 三级/600
   │    提问列表项（可点击）：
   │      第一行「第 N 次提问」(12px/600) + 时间（等宽 11px 四级）
   │      第二行 提问原文（12px 一级）
   │      第三行「软件下载 · 检索 · 4.1s」（11px 四级）
   │    选中项：底色 primary 10%，边框 primary 35%，标题文字 primary
   │
   └─ 右栏 Card  填充（实际 912）
        ├ 分组标题「用户问题」11px 三级/600
        ├ 问题文本（code-bg 底，圆角 6，内边距 10/12）
        ├ 分组标题「意图判定」
        ├ [软件下载] 标签  置信度 0.71  →  [RETRIEVE] 标签  进入知识库检索
        ├ 分隔线
        ├ 分组「预披露」（sparkles 图标 + 副标题「代码自动执行」）
        │   自动标签：[视觉] [软件] [环境配置]      ← purple 标签
        │   标签命中：视觉方向详解 0.81 · 各方向所需软件 0.77
        ├ 分组「轮次 1」（hash 图标 + 副标题「分片检索 · 已用 1/3 轮」）
        │   💭 斜体三级文字：思考内容
        │   🔧 chunk_search_by_tags  query=「…」tags=「…」
        │      └ 结果块（code-bg）：共 8 条结果 · score 最高/最低/平均
        │                         [1] score=0.7912  [06-视觉方向详解]  …
        ├ 分组「轮次 2」（同上，「软件资源清单 · 已用 1/1 轮」）
        │   💭 思考 → 🔧 software_resource_list → 结果块
        ├ 分隔线
        └ 分组「最终答案」（flag 图标，标题用 ok 色，副标题「1.2s · 未走兜底」）
            答案正文
```

### 轮次与思考/工具的缩进

轮次分组标题下，内容整体左缩进 22px。

### 事件渲染映射（`events` 是 JSON 字符串，需 `JSON.parse`）

| 事件 type | 渲染 |
|---|---|
| `intent` | 顶部「意图判定」区块（intent 标签 + confidence + action 标签） |
| `pre_disclose` | 「预披露」分组：tags 渲染为紫色标签，hits 渲染为「名称 分数」列表 |
| `reasoning` | 💭 brain 图标 + 斜体三级文字 |
| `tool_call` | 🔧 wrench 图标 + 等宽工具名（primary 色）+ 等宽参数（三级文字）；按 `round` 归入对应轮次分组 |
| `tool_result` | 缩进的结果块（code-bg 底）；`blocked=true` 时加醒目标记「已达轮次上限，未执行」 |
| `content` | 「最终答案」区块正文 |

### 完整 prompt 快照

右栏底部（或答案之后）提供入口查看 `prompt`（JSON 字符串，可能为 null）：

- 用折叠面板或抽屉展示 `JSON.parse(prompt)` 的结果，按 role 分段
- `prompt` 为 null 时显示「未执行状态图，无 prompt 快照」而不是报错
- 这一项的用途是排查"模型实际看到了什么"，请保留原始结构，不要摘要化

### 纵向结构（gap 16）

```

   左：H1「AI 对话分析」20px/700
       副标题「趋势按会话统计 · 意图与动作按提问统计」13px 三级文字
   右：[最近 7 天 ▾] 周期选择器（24h / 7d / 30d）

② 概览指标行（4 张 Card 等宽，gap 16）              高 106
   每张：标题 12px 三级 → 数值 26px/700 → 变化说明 11px

③ 中部行（gap 16）                                高 366
   ├─ Card「意图分布」填充（实际 776）
   │    副标题「共 N 次提问 · 分类器输出结果」11px 四级
   │    条形列表，每行：标签 88px + 底槽 560px(高 8, 圆角 4) + 计数以等宽 12px
   │    条色：主要意图 primary / 次要 cyan / 无关问题 err / 问候 四级文字
   └─ Card「处理动作分布」宽 400
        堆叠横条（高 10，圆角 5）：检索 / 拒答 / 直接回复 三段
        图例 3 行：色块 8px + 名称（填充）+ 次数（等宽）+ 占比（等宽，右对齐 56px）
        分隔线
        副标题「拒答原因 TOP 3」
        3 行：色点 6px + 意图名（等宽 11px）+ 次数

④ 底部行（gap 16）                                高 292
   ├─ Card「会话量趋势」填充
   │    副标题「每日新增会话数 · 峰值在 MM-DD」11px 四级
   │    柱状图：用 `@ant-design/charts` 的 `Column`（该项目已自带该依赖，`panel` 页有先例）。
   │    峰值柱用 primary，其余用 primary 35%；自带悬浮提示显示数值
   └─ Card「检索工具使用」宽 440
        副标题「调用次数 · 兜底检索越高说明标签覆盖越差」11px 四级
        5 行，每行：工具名（等宽 12px）+ 次数（等宽）+ 细进度条（高 6）
        其中「chunk_search 兜底」一行用 warn 色文字 + warn 底色轨道
```

### 概览指标卡内容

| 指标 | 字段 | 说明 |
|---|---|---|
| 会话总数 | `overview.conversationCount` | 反映多少人来问 |
| 消息数 | `overview.questionCount` | **副标题注明「消息数 = 用户提问数（不含助手回复）」** |
| 拒答率 | 由 `refusedCount / questionCount` 计算 | 百分比，保留 1 位小数 |
| 兜底检索率 | `overview.fallbackRate` | 百分比；这是标签覆盖率的体温计，用 warn 色描边强调 |

### 空数据

所有统计区块在无数据时显示零值 / 空状态，**不得**报错或显示骨架屏不动。
