# 项目简介

蓝网官方网站是蓝网实验室的官方门户系统，用于展示实验室信息、管理招新报名、进行考核评估等。

## 目标用户

- ** prospective members**：了解团队方向、报名加入、参加考核。
- **团队成员**：管理个人信息、经历、查看内部资料。
- **管理员**：审核报名、出题、评分、发布考核决策、管理权限。

## 技术栈概览

| 层级 | 主要技术 |
|------|---------|
| 前端 | Next.js 15 + React 19 + TypeScript + Ant Design 6 |
| 后端 | Spring Boot 3.5.10 + Java 21 + DDD 四层架构 |
| 数据库 | PostgreSQL 15+ |
| 缓存/消息 | Redis + RabbitMQ |
| 对象存储 | MinIO / 阿里云 OSS |

详细版本与运行时架构见 [02-02-技术架构](./02-02-技术架构.md)。

## Monorepo 结构

```
bluenet_web2.2/
├── src/
│   ├── frontend/          # 前端项目（Next.js）
│   └── backend/           # 后端项目（Spring Boot）
├── docs/                  # 文档目录
├── docker/                # Docker 配置
└── openspec/              # OpenSpec 变更管理
```

- 前端源码：`src/frontend/`
- 后端源码：`src/backend/`
- 文档：`docs/`
- Docker 与 Compose：`docker/`
