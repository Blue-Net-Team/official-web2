# 快速开始

本指南帮助你在 15 分钟内把 BlueNet 项目运行起来。如需完整的依赖安装与变量说明，请参考 [04-01-环境配置](./04-运维部署/04-01-环境配置.md)。

## 环境要求

| 工具 | 版本要求 | 说明 |
|------|---------|------|
| JDK | 21+ | 后端运行环境 |
| Maven | 3.9+ | 后端构建工具 |
| Node.js | 20+ | 前端运行时 |
| pnpm | 9+ | 前端包管理器 |
| PostgreSQL | 15+ / 17+ | 主数据库 |
| MinIO | 最新版 | 对象存储 |
| Docker | 可选 | 容器化部署 |

## 方式一：本地开发（推荐新手）

适用于本地开发调试，只需安装必要的服务。

```bash
# 1. 克隆项目
git clone https://github.com/your-org/bluenet_web2.2.git
cd bluenet_web2.2

# 2. 安装 Git Hooks
./scripts/hooks/install.sh

# 3. 安装 PostgreSQL 并创建数据库
# Windows: https://www.postgresql.org/download/windows/
# Linux: sudo apt install postgresql postgresql-contrib
psql -U postgres
CREATE DATABASE db_blue_net;
\q

# 4. 安装 MinIO（可选，用于文件存储）
# https://min.io/download

# 5. 配置后端环境变量
cd src/backend
cp .env.example .env
# 编辑 .env 文件，填写实际配置

# 6. 启动后端
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev

# 7. 启动前端（新终端）
cd src/frontend
pnpm install
pnpm dev
```

访问前端：`http://localhost:3000`

访问后端 API：`http://localhost:8080`

## 方式二：Docker Compose（推荐团队开发）

使用 Docker 一键启动所有服务。

```bash
# 1. 克隆项目
git clone https://github.com/your-org/bluenet_web2.2.git
cd bluenet_web2.2

# 2. 安装 Git Hooks
./scripts/hooks/install.sh

# 3. 创建环境变量文件（复制模板并编辑）
cp docker/.env.example docker/.env
# 编辑 docker/.env，填写实际值，特别注意：
# - MINIO_PUBLIC_URL 需填写宿主机可访问的地址（如 http://192.168.1.100:7000）
# - DB_PASSWORD / MINIO_SK 等密码必须修改

# 4. 启动所有服务
cd docker
docker compose --profile full up -d

# 5. 查看服务状态
docker compose ps
```
