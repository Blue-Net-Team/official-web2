# Delta: ai-trace-admin

## ADDED Requirements

### Requirement: 会话详情页移动端上下布局
AI 对话详情页（`/admin/ai-traces/conversations/[id]`）SHALL 在移动端（`isMobile = !screens.md`）将"左侧固定 264px 提问导航 + 右侧事件流"的左右双栏改为上下布局，解决窄视口下两栏互相挤压、每行仅显示一个字的问题。

移动端布局 SHALL：
- 顶部保留返回链接 + 会话 ID + 提问数标签
- 提问导航渲染为横向滚动胶囊条（chip）："第 N 次提问 + 时间"，激活项使用强调色高亮
- 当前提问的摘要行（意图 / 动作 / 耗时）显示在胶囊条下方
- 原始事件流详情卡片占满全宽渲染

#### Scenario: 移动端提问导航横向滚动
- **WHEN** 用户在移动端视口打开会话详情页
- **THEN** 各次提问以横向滚动胶囊展示，可左右滑动切换
- **AND** 点击胶囊切换右侧详情，行为与桌面端点击左侧列表一致

#### Scenario: 事件流全宽展示
- **WHEN** 用户在移动端选中某次提问
- **THEN** 该提问的完整事件流在下方全宽卡片内渲染，文本正常换行、不逐字折行

#### Scenario: 桌面端保持双栏
- **WHEN** 视口大于等于 md 断点
- **THEN** 页面 SHALL 保持左侧 264px 提问导航 + 右侧事件流的双栏布局，与改动前一致

### Requirement: 对话分析面板移动端纵向堆叠
对话分析页（`/admin/ai-traces/statistics`）SHALL 在移动端将横向排列的卡片改为纵向堆叠：顶部统计卡片以 2×2 栅格渲染，趋势图卡片与检索工具使用卡片全宽纵向排列，所有固定像素宽度（如 440px 侧栏、280px 条形最大宽度）在移动端取消或改为百分比。

#### Scenario: 移动端指标卡 2×2 栅格
- **WHEN** 用户在移动端视口打开分析面板
- **THEN** 总会话/总提问/平均响应/拒答率以 2×2 栅格卡片展示，无溢出

#### Scenario: 移动端图表全宽堆叠
- **WHEN** 移动端渲染趋势图与工具使用卡片
- **THEN** 两卡片全宽纵向排列，趋势图高度按移动视口缩减，工具条形图宽度按容器自适应
- **AND** 页面无横向滚动

#### Scenario: 桌面端保持分栏
- **WHEN** 视口大于等于 md 断点
- **THEN** 分析面板 SHALL 保持桌面端横向分栏布局与固定宽度，与改动前一致
