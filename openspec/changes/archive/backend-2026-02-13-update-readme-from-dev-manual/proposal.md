## Why

当前 README.md 与 docs/官网功能与开发手册.md 存在内容不一致的问题。开发手册详细记录了系统的核心功能和架构设计，但 README 未能完整反映这些最新信息。为了让新成员和外部开发者能够快速了解项目全貌，需要根据开发手册同步更新 README 文档。

## What Changes

- 重新梳理核心功能描述，使其与开发手册保持一致
- 更新技术架构图，采用开发手册中的 Mermaid 流程图
- 补充缺失的模块说明（成员模块、引流模块等）
- 完善数据库设计部分，添加 ER 图
- 优化项目结构描述
- 更新快速开始指南

## Capabilities

### New Capabilities
- `readme-sync`: 根据开发手册同步 README 文档内容
- `docs-improvement`: 改进文档结构和可读性，包括 ER 图、架构图的展示

### Modified Capabilities
- 无（此变更仅涉及文档更新，不涉及功能规格的修改）

## Impact

- **文件**: README.md（主文档）
- **参考**: docs/官网功能与开发手册.md（变更依据）
- **范围**: 纯文档更新，不影响代码、API 或依赖
- **风险**: 无代码变更风险，仅需确保文档准确性
