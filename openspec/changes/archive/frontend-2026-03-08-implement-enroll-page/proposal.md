## Why

蓝网科技创新团队需要一个新的报名页面，让有意向加入的学生能够方便地提交报名信息。目前团队招新流程缺少一个统一的在线报名入口，需要一个功能完善、视觉美观的报名页面来提升用户体验和招新效率。

## What Changes

- 新增报名页面路由 `/enroll`
- 实现方向选择功能（计算机视觉、结构设计、嵌入式开发三个方向）
- 实现头像上传功能，支持图片预览和删除
- 实现报名表单，包含：
  - 基本信息：头像、姓名、学号
  - 联系信息：邮箱
  - 学籍信息：学院（下拉选择）、专业、年级（下拉选择）
  - 报名意向：意向方向
  - 自我介绍（100-500字，带实时字数统计）
  - 内推码（选填）
- 实现表单验证和错误提示
- 实现粒子背景、入场动画等视觉效果
- 对接后端报名 API，提交报名数据（包含头像）
- 实现报名成功/失败的状态反馈
- 响应式布局，适配移动端和桌面端

## Capabilities

### New Capabilities
- `enroll-page`: 报名页面整体功能，包含UI展示、表单处理、数据提交
- `enroll-form`: 报名表单组件，包含字段验证和交互反馈
- `direction-selector`: 方向选择组件，支持三个方向的切换展示
- `avatar-upload`: 头像上传组件，支持图片选择、预览、删除

### Modified Capabilities
- 无

## Impact

- 前端路由配置：新增 `/enroll` 路由
- API 集成：需要对接后端报名接口，支持头像上传
- 组件库：使用 Ant Design 表单组件和上传组件
- 样式系统：遵循项目现有的暗色科技风格设计
- 依赖：可能需要文件上传处理库
