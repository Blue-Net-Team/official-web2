## Context

本项目是蓝网科技创新团队的企业级官方网站，使用 Next.js + React + Ant Design 技术栈。报名页面是团队招新的重要入口，需要实现一个美观、易用的在线报名功能。

UI 设计稿位于 `docs/UI/enroll/index.html`，采用暗色科技风格设计，包含：
- 动态网格背景和光晕效果
- 左侧方向选择侧边栏（桌面端）
- 中央报名表单卡片
- 响应式布局支持移动端

## Goals / Non-Goals

**Goals:**
- 实现符合设计稿视觉效果的报名页面
- 支持三个方向的选择切换（计算机视觉、结构设计、嵌入式开发）
- 实现完整的报名表单功能，包含字段验证
- 对接后端 API 提交报名数据
- 提供良好的用户反馈（加载状态、成功/失败提示）
- 实现响应式布局，适配各种屏幕尺寸

**Non-Goals:**
- 不支持报名表单的草稿保存功能
- 不支持上传附件（如简历、作品集）
- 不涉及后台管理功能（审核、查看报名列表等）

## Decisions

### 1. 页面结构组织
- **决策**: 使用 Next.js App Router 的页面路由，路径为 `/enroll`
- **理由**: 符合项目现有架构，支持服务端渲染和客户端交互

### 2. 组件拆分策略
- **决策**: 将页面拆分为三个主要组件
  - `EnrollPage`: 页面容器，处理布局和背景效果
  - `DirectionSelector`: 方向选择组件，支持三个方向的切换
  - `EnrollForm`: 报名表单组件，包含所有表单字段和验证逻辑
- **理由**: 单一职责原则，便于维护和测试；DirectionSelector 可在其他页面复用

### 3. 状态管理
- **决策**: 使用 React useState 管理本地状态，不使用全局状态管理
- **理由**: 报名页面状态相对独立，不需要与其他页面共享状态

### 4. 样式方案
- **决策**: 使用 CSS Modules + 项目全局样式变量
- **理由**: 符合项目现有规范，便于维护；需要实现设计稿中的特殊效果（光晕、动画等）

### 5. 表单验证
- **决策**: 使用 Ant Design Form 组件的内置验证功能
- **理由**: 与项目 UI 库一致，验证规则清晰，用户体验好

### 6. API 集成
- **决策**: 使用项目现有的 axios 拦截器封装，创建 enrollService
- **理由**: 符合项目规范，统一处理认证和错误

## Risks / Trade-offs

- **[Risk]** 设计稿中的复杂动画效果可能影响低端设备性能
  - **Mitigation**: 使用 CSS `prefers-reduced-motion` 媒体查询，为偏好减少动画的用户提供简化版本

- **[Risk]** 表单提交失败后的数据丢失
  - **Mitigation**: 在提交前进行完整的客户端验证；提交失败时保留表单数据，提示用户重新提交

- **[Trade-off]** 方向选择侧边栏在移动端需要重新设计
  - 桌面端使用左侧固定侧边栏
  - 移动端改为顶部横向滚动选择器或下拉选择
