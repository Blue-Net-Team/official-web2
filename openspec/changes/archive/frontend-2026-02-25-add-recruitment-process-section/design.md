# 招新流程组件设计文档

## 概述

本文档详细描述招新流程区块的视觉设计和交互设计，基于Pixso设计稿实现。

---

## 布局结构

### 整体布局

```
┌─────────────────────────────────────────────────────────────────┐
│                     RecruitmentProcess                          │
│                    (1270px × 780px)                             │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                      标题区域                            │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  ┌──────────┐   ┌────────┐   ┌──────────┐   ┌────────┐   ┌──────────┐
│  │  卡片1   │ ← │ 箭头 │ → │  卡片2   │ ← │ 箭头 │ → │  卡片3   │
│  │ 260×340  │   │ 64×64  │   │ 260×340  │   │ 64×64  │   │ 260×340  │
│  └──────────┘   └────────┘   └──────────┘   └────────┘   └──────────┘
└─────────────────────────────────────────────────────────────────┘
```

### 容器布局属性

- **Display**: Flex
- **Flex Direction**: Column
- **Align Items**: Center
- **Padding**: 70.5px 112px
- **Gap**: 20px (标题与卡片区域之间)

### 卡片容器布局

- **Display**: Flex
- **Flex Direction**: Row
- **Justify Content**: Space Between
- **Align Items**: Center
- **Padding**: 23px 0 60px

## 组件详情

### 流程卡片结构

```
┌─────────────────────────────────────┐
│ ┌──────┐                            │
│ │ 图标 │  标题 (20px Bold)          │
│ │32×32 │                            │
│ └──────┘                            │

│                                     │
```

### 卡片状态

#### 默认状态
- 边框: 1px solid #E86835
- 背景: 透明（继承父容器背景）

#### 悬停状态 (可选增强)
- 边框: 保持
- 阴影: 添加轻微发光效果
- 过渡: 300ms ease-out

## 响应式设计

### 桌面端 (>= 1270px)
- 完整三卡片水平布局
- 箭头指示器完全显示

### 平板端 (768px - 1269px)
- 卡片尺寸适当缩小
- 保持水平布局

### 移动端 (< 768px)
- 卡片垂直堆叠
- 箭头改为向下指示
- 或启用横向滚动

---

## 动画与过渡

### 建议的动画效果

1. **卡片入场动画**
   - 延迟: 依次延迟100ms
   - 效果: 从下方淡入上移
   - 时长: 500ms
   - 缓动: cubic-bezier(0.4, 0, 0.2, 1)

2. **按钮悬停效果**
   - 背景: 轻微变暗
   - 缩放: 1.02
   - 时长: 200ms

3. **箭头呼吸效果** (可选)
   - 透明度: 0.6 → 1 → 0.6
   - 时长: 2s
   - 循环: infinite
