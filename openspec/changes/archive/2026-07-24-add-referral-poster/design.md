## Context

内推码（`internal_referral_code`）已在后端实现生成与存储：`tb_user.internal_referral_code` 持有成员自己的 8 位大写字母数字码，`tb_enroll.internal_referral_code` 记录报名时填写的码。但当前用户资料接口 `GET /api/v1/user/info` 不返回该字段，前端也没有任何入口展示成员自己的码，导致报名页的内推码输入框无法被实际使用。

本次变更要在个人主页增加"我要内推"入口，支持生成带二维码的海报图片和可复制链接；同时让报名页支持通过 URL 参数自动填写内推码。

## Goals / Non-Goals

**Goals:**
- 当前登录用户可在个人主页查看自己的内推码。
- 用户可复制含内推码的报名链接（`/enroll?ref=ABCDEF12`）。
- 用户可下载一张海报图片，图片包含报名页二维码（扫码自动填码）和内推码、内推人姓名。
- 报名页读取 URL 中的 `ref` 参数并自动填入"内推码"字段。
- 内推码输入框在前端自动转大写并校验 8 位大写字母数字格式。
- 提供海报模板设计器，方便后续新增模板时调整动态元素坐标。

**Non-Goals:**
- 不新增内推统计/排行榜功能。
- 不校验报名时填写的内推码是否真实存在（保持现有后端行为）。
- 不修改内推码生成逻辑。
- 不将生成的海报图片上传到后端或对象存储。

## Decisions

### 1. 海报生成放在前端

**选择**：使用 `qrcode.react` 生成二维码，使用 Canvas 2D API 将海报模板底图、二维码、文字合成为图片。

**理由**：
- 项目现有的 `Qrcode` 后端模块是"上传图片文件并保存 fileId"，不适合直接生成 URL 二维码。
- 海报模板是复杂的视觉设计（渐变、阴影、装饰元素），用 CSS/JS 完全还原成本高；使用设计师提供的留白底图再叠加动态内容更可靠。
- 前端即时生成，不占用后端资源，不需要文件存储。

**替代方案**：后端用 ZXing 合成图片。放弃原因：增加后端依赖和计算开销，且模板坐标调整仍需要前端预览，不如整套放在前端。

### 2. 海报底图作为 public 静态资源

**选择**：将 `inf.png` 放到 `public/referral-posters/inf.png`。

**理由**：Canvas 加载图片需要可直接通过 URL 访问的地址，public 目录下的文件不会被 Next.js 打包转换，路径稳定。

### 3. 模板配置与坐标调试器

**选择**：用 TypeScript 配置文件定义模板坐标，并提供一个独立的 `/admin/referral-poster-design` 页面用于拖拽定位。

**理由**：
- 用户已说明无法提供坐标且后续可能新增模板，调试器可以复用。
- 配置文件比硬编码更易于维护和替换。
- 管理员页面与业务组件解耦，避免调试代码污染生产组件。

### 4. 分享链接使用 `?ref=`

**选择**：报名页通过 `ref` query 参数预填内推码，参数值自动转换为大写。

**理由**：
- 简短，不影响现有 `direction` 参数。
- "ref" 是 referral 的通用缩写，语义明确。

### 5. 内推人显示 `username`

**选择**：海报上的"内推人"字段使用 `username`（真实姓名/登录名），而非 `nickname`。

**理由**：用户明确要求。

## Risks / Trade-offs

| 风险 | 缓解措施 |
|---|---|
| 海报坐标目测不准确，生成后文字/二维码偏移 | 提供模板设计器页面，可在浏览器中拖拽精调；初版坐标基于网格图测量得出 |
| Canvas 跨域问题导致无法绘制底图 | 底图放在同域 public 目录下，不存在跨域 |
| 二维码尺寸过小导致扫描困难 | 模板中二维码区域 170×170，在 1024px 宽海报上足够大；设计器可调整 |
| 字体在客户端缺失导致海报文字样式不一致 | 使用通用字体（Arial / sans-serif）并回退；设计器可预览 |
| 低版本浏览器不支持 Canvas toBlob/toDataURL | 项目面向现代浏览器，且可降级为仅提供链接复制 |

## Migration Plan

1. 将 `src/frontend/src/assets/inf.png` 复制到 `public/referral-posters/inf.png`。
2. 后端新增 `internalReferralCode` 字段到用户资料响应，无需数据库迁移。
3. 前端安装 `qrcode.react`。
4. 新增组件、页面、配置文件。
5. 验证：登录成员访问个人主页 → 点击"我要内推" → 复制链接 → 在新窗口打开报名页 → 确认内推码已预填 → 下载海报 → 扫码确认跳转并填码。
