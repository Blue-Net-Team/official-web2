## ADDED Requirements

### Requirement: 所有数据库表必须包含中文注释
数据库中的所有表必须包含中文表级注释，说明表的用途和业务含义。

#### Scenario: 表注释已添加
- **WHEN** 开发人员查询表注释
- **THEN** 每张表都返回对应的中文注释说明

#### Scenario: 表注释与开发手册一致
- **WHEN** 对比数据库表注释与开发手册
- **THEN** 所有表注释内容必须与开发手册表设计定义保持一致

### Requirement: 所有数据库列必须包含中文注释
数据库表中的所有列必须包含中文列级注释，说明字段的业务含义、数据类型限制和业务规则。

#### Scenario: 列注释已添加
- **WHEN** 开发人员查询列注释
- **THEN** 每列都返回对应的中文注释说明

#### Scenario: 枚举类型列注释包含可选值
- **WHEN** 列是枚举类型（如 direction, gender, status 等）
- **THEN** 注释必须说明所有可选值及其含义

#### Scenario: 软删除字段有明确注释
- **WHEN** 列是 deleted 字段
- **THEN** 注释必须说明这是软删除标记，true表示已删除

### Requirement: 所有索引必须包含中文注释
数据库中的所有索引必须包含中文注释，说明索引的用途和优化场景。

#### Scenario: 索引注释已添加
- **WHEN** 开发人员查询索引注释
- **THEN** 每个索引都返回对应的中文注释说明

#### Scenario: 索引注释说明查询场景
- **WHEN** 查看索引注释
- **THEN** 注释必须说明该索引用于优化哪种查询场景

### Requirement: 迁移脚本必须可重复执行
Flyway 迁移脚本必须使用幂等的 COMMENT 语句，确保可以重复执行而不会报错。

#### Scenario: 重复执行迁移脚本
- **WHEN** 多次执行 V5__add_table_column_comments.sql
- **THEN** 每次执行都成功，且注释内容保持一致

#### Scenario: 迁移脚本在新环境执行
- **WHEN** 在新环境执行迁移脚本
- **THEN** 所有表、列、索引都正确添加注释

### Requirement: 注释内容必须使用中文
所有数据库对象的注释必须使用中文，便于团队成员理解。

#### Scenario: 验证注释语言
- **WHEN** 查询任意表、列、索引的注释
- **THEN** 返回的注释内容为中文
