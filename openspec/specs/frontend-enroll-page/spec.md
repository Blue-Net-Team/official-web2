## ADDED Requirements

### Requirement: 页面布局与视觉效果
报名页面 SHALL 实现符合设计稿的视觉效果，包含动态网格背景、光晕效果、粒子效果和科技感设计。

#### Scenario: 页面加载时展示背景效果
- **WHEN** 用户访问报名页面
- **THEN** 页面显示动态网格背景动画
- **AND** 页面显示浮动光晕效果
- **AND** 页面显示粒子浮动效果

#### Scenario: 响应式布局适配
- **WHEN** 用户在桌面端访问页面
- **THEN** 显示左侧方向选择侧边栏和中央报名表单
- **WHEN** 用户在移动端访问页面
- **THEN** 方向选择器显示为卡片形式在表单内

### Requirement: 方向选择功能
用户 SHALL 能够在三个方向（计算机视觉、结构设计、嵌入式开发）之间进行选择。

#### Scenario: 默认选中第一个方向
- **WHEN** 页面首次加载
- **THEN** 默认选中"计算机视觉"方向
- **AND** 对应方向卡片显示激活状态样式

#### Scenario: 切换方向
- **WHEN** 用户点击其他方向卡片
- **THEN** 被点击方向显示激活状态
- **AND** 之前选中的方向恢复默认状态
- **AND** 表单中的意向方向字段同步更新

#### Scenario: 方向样式区分
- **WHEN** 计算机视觉方向被选中
- **THEN** 显示蓝紫色主题样式
- **WHEN** 结构设计方向被选中
- **THEN** 显示橙红色主题样式
- **WHEN** 嵌入式开发方向被选中
- **THEN** 显示绿色主题样式

#### Scenario: 移动端方向选择
- **WHEN** 用户在移动端访问页面
- **THEN** 在表单内显示方向选择卡片区域
- **AND** 方向卡片以网格布局展示
- **AND** 支持点击选择方向

### Requirement: 头像上传功能
报名页面 SHALL 支持用户上传个人头像。

#### Scenario: 头像上传区域展示
- **WHEN** 页面加载完成
- **THEN** 显示圆形头像上传区域
- **AND** 显示上传图标和提示文字

#### Scenario: 选择和预览头像
- **WHEN** 用户点击头像上传区域
- **THEN** 打开文件选择对话框
- **WHEN** 用户选择图片文件
- **THEN** 在上传区域预览选中的图片
- **AND** 显示删除按钮

#### Scenario: 删除已上传头像
- **WHEN** 用户 hover 已上传头像
- **THEN** 显示删除按钮
- **WHEN** 用户点击删除按钮
- **THEN** 清除已上传的头像
- **AND** 恢复默认上传状态

#### Scenario: 头像验证
- **WHEN** 用户选择的文件不是图片格式
- **THEN** 显示"请选择图片文件"错误提示
- **WHEN** 用户选择的图片超过大小限制
- **THEN** 显示"图片大小不能超过XMB"错误提示

### Requirement: 报名表单功能
报名页面 SHALL 提供完整的报名表单，收集用户的基本信息和报名意向。

#### Scenario: 表单字段展示
- **WHEN** 页面加载完成
- **THEN** 表单显示以下字段：
  - 头像（必填）
  - 姓名（必填）
  - 学号（必填）
  - 邮箱（必填）
  - 学院（必填，下拉选择）
  - 专业（必填）
  - 年级（必填，下拉选择）
  - 意向方向（必填，与方向选择器同步）
  - 自我介绍（必填，100-500字）
  - 内推码（选填）

#### Scenario: 学院选择
- **WHEN** 用户点击学院下拉框
- **THEN** 显示可选学院列表：
  - 计算机学院
  - 软件学院
  - 电子信息学院
  - 机械工程学院
  - 土木建筑工程学院
  - 其他学院

#### Scenario: 年级选择
- **WHEN** 用户点击年级下拉框
- **THEN** 显示可选年级列表：
  - 大一
  - 大二

#### Scenario: 自我介绍字数统计
- **WHEN** 用户在自我介绍文本框输入文字
- **THEN** 实时显示当前字数（如"150/500"）
- **WHEN** 字数少于100字
- **THEN** 显示字数不足提示
- **WHEN** 字数达到500字
- **THEN** 禁止继续输入

#### Scenario: 表单字段验证
- **WHEN** 用户提交表单时头像未上传
- **THEN** 显示"请上传头像"错误提示
- **WHEN** 用户提交表单时姓名为空
- **THEN** 显示"请输入姓名"错误提示
- **WHEN** 用户提交表单时学号为空
- **THEN** 显示"请输入学号"错误提示
- **WHEN** 用户输入的学号格式不正确（非12-13位数字）
- **THEN** 显示"请输入正确的学号格式"错误提示
- **WHEN** 用户提交表单时邮箱为空
- **THEN** 显示"请输入邮箱"错误提示
- **WHEN** 用户输入的邮箱格式不正确
- **THEN** 显示"请输入正确的邮箱格式"错误提示
- **WHEN** 用户提交表单时学院未选择
- **THEN** 显示"请选择学院"错误提示
- **WHEN** 用户提交表单时专业为空
- **THEN** 显示"请输入专业"错误提示
- **WHEN** 用户提交表单时年级未选择
- **THEN** 显示"请选择年级"错误提示
- **WHEN** 用户提交表单时自我介绍少于100字
- **THEN** 显示"自我介绍至少需要100字"错误提示

#### Scenario: 表单提交成功
- **WHEN** 用户填写完整且正确的表单信息
- **AND** 用户点击提交按钮
- **THEN** 显示提交加载状态
- **AND** 向后端发送报名请求
- **WHEN** 后端返回成功响应
- **THEN** 显示报名成功提示
- **AND** 清空表单数据

#### Scenario: 表单提交失败
- **WHEN** 用户提交表单
- **AND** 后端返回错误响应
- **THEN** 隐藏加载状态
- **AND** 显示错误提示信息
- **AND** 保留表单数据供用户修改

### Requirement: API 集成
报名页面 SHALL 通过 API 与后端通信，提交报名数据。

#### Scenario: 提交报名数据
- **WHEN** 用户提交表单
- **THEN** 调用 POST /api/enrollment 接口
- **AND** 请求体包含：avatar, name, studentId, email, college, major, grade, direction, introduction, referralCode
- **AND** 请求 SHALL 不需要认证头

#### Scenario: 头像上传
- **WHEN** 用户选择头像文件
- **THEN** 将头像文件转换为 Base64 或上传至文件服务
- **AND** 在提交表单时包含头像数据

#### Scenario: 处理网络错误
- **WHEN** API 请求网络超时或失败
- **THEN** 显示"网络错误，请稍后重试"提示
- **AND** 允许用户重新提交

### Requirement: 动画与交互效果
报名页面 SHALL 提供流畅的动画和交互效果。

#### Scenario: 页面入场动画
- **WHEN** 页面加载完成
- **THEN** 报名卡片从下方淡入
- **AND** 方向选择侧边栏从左侧淡入
- **AND** 表单各区域依次滑入显示

#### Scenario: 输入框焦点效果
- **WHEN** 用户聚焦输入框
- **THEN** 输入框边框变为高亮色
- **AND** 显示发光阴影效果

#### Scenario: 错误提示动画
- **WHEN** 表单验证失败
- **THEN** 错误输入框显示抖动动画
- **AND** 边框变为红色并显示发光效果
